## 六、关键不变量

1. Native 和 Immersive 模式下 `activeSurface` 必须为 `null`
2. Task 模式下必须且只能有一个非空 `activeSurface`
3. Clean 模式禁止 Task
4. Safe 可打断所有状态
5. 退出后 Windows 原生桌面可用
6. 不允许一个全屏透明窗口无差别拦截鼠标
