# Project D V5.0 产品需求文档

版本：V5.0 Draft 1  
日期：2026-07-24  
目标平台：Windows 10 22H2、Windows 11 x64  
目标版本：公开免费 Beta 候选版  
依据：V1.1 验收标准、V2.1/V3.0 商业化方案、V4 免费发布路线、Stage 50 当前实现

## 1. 文档结论

V5 的核心目标不是继续堆叠页面，而是把 Project D 从“功能较完整的受控内测客户端”推进为“可公开验证、可恢复、可维护的 Windows 免费桌面助手”。

当前判断：

| 维度 | 当前状态 | V5目标 |
|---|---|---|
| 客户端核心功能 | 约 92%-95% | 核心路径完整、无已知 P0 |
| 自动化质量 | 202 Node、2组件、11 Electron E2E通过 | 保持全绿并扩展媒体、安装、恢复覆盖 |
| 公开免费 Beta 准备度 | 约 55%-65% | 满足公开 Beta 门槛 |
| 付费商业化准备度 | 约 35%-45% | V5不以付费上线为目标 |
| 外部证据 | 硬件、签名、授权、法务、长浸泡未闭环 | 形成可审计发布证据包 |

## 2. 产品定位

Project D 是 Windows 桌面空间助手，而不是传统文件管理器、单一壁纸播放器或悬浮聊天窗口。

产品承诺：

1. 桌面整理直接服务于真实 Windows 桌面，任何文件动作先预览、可确认、可撤销、可恢复。
2. 壁纸、天气和桌宠是桌面的自然延伸，不应遮挡系统图标、应用窗口或导致白屏。
3. AI 负责对话、建议和生成结构化计划，不得绕过用户确认执行高风险动作。
4. 本地整理、恢复和退出不依赖账号、支付、云端或 AI 服务。
5. 在轻薄本、核显和电池环境下优先保证稳定与低占用。

## 3. V5发布范围

### 3.1 包含

- 真实桌面扫描、分类、容器布局、文件夹预览、搜索、门户、场景和自动规则。
- 整理计划预览、冲突检测、执行、撤销、中断恢复和安全归位。
- 静态壁纸、受控动态壁纸、自定义壁纸库、壁纸创作和多显示器映射。
- 雨、雪、雾、落叶、星光和光晕等可降级桌面特效。
- 多桌宠选择、人格、上下文对话、全桌面移动、真实动作素材和本地桌宠制作。
- DeepSeek、MiMo、OpenAI-compatible 等用户自带 Key 的可选 AI 接入。
- 深色/浅色/跟随系统、隐私暂停、诊断导出、缓存清理、数据导出与彻底删除。
- 托盘、快捷键、纯净桌面、异常恢复、安装、卸载和手动更新。

### 3.2 不包含

- 生产账号、云同步、云备份和跨设备状态同步。
- 微信、支付宝、银行卡支付及正式会员权益。
- Project D 托管的公共 AI Key 或图片生成额度。
- 壁纸社区、UGC 商店、在线投稿和内容分发平台。
- macOS、Linux、移动端。
- 未取得分发授权的壁纸、角色、字体、音频和视频。

### 3.3 延后到V6或商业版

- 正式支付与账号服务端。
- 云端遥测、远程运维看板和客服工单平台。
- 自动生成式壁纸云服务。
- 社区、创作者分成和素材商城。
- Live2D/Spine 商业角色系统。

## 5. 功能需求

## FR-1 桌面安全与生命周期

### FR-1.1 启动与退出

- 首次启动、重复启动、快捷方式启动和开机启动均不得产生白屏遮挡。
- 正常退出、托盘退出、任务管理器强杀、系统关机和崩溃后必须恢复桌面图标、任务栏和壁纸状态。
- idle 状态退出不得写入虚假的“接管中”恢复标记。
- 恢复失败必须提供可执行的本地恢复入口，不以重启 Explorer 作为默认方案。

### FR-1.2 纯净桌面

- 进入后隐藏桌面图标和任务栏，显示 Project D 当前壁纸与特效。
- 默认 `Esc` 退出；支持用户重新绑定。
- 保持显示器唤醒使用系统电源阻止器，不模拟键盘输入。
- 退出、崩溃、睡眠唤醒和显示器变化后恢复系统状态。

### FR-1.3 多显示器

- 支持单屏、双屏、三屏、负坐标屏幕、横屏和竖屏。
- 保存每个显示器的壁纸、裁剪策略、质量档位和场景映射。
- 热插拔后保留映射，重新连接时恢复。
- DPI 与主屏切换后窗口、桌宠和容器保持可见、可点击。

## FR-2 桌面整理

### FR-2.1 双模式

- 默认模式：透明容器浮于真实桌面壁纸之上，不移动真实文件。
- 原生布局实验模式：对 Explorer 图标坐标进行快照、排列和回滚，不改变文件路径。
- 两种模式必须明确区分，不能让用户误以为虚拟分类已经移动文件。

### FR-2.2 分类与防呆

- 文件夹、文件、程序、压缩包、图片、媒体、代码和其他类别正确识别。
- `.lnk` 指向文件夹时归类为文件夹；断链快捷方式保持可见并提示。
- 系统文件、临时文件、Office 锁文件和恢复脚本不进入普通整理动作。
- 对同名、占用、无权限、跨盘、断链和路径过长给出冲突说明。

### FR-2.3 文件夹与预览

- 使用易识别的文件夹视觉，整理前后保持一致。
- 文件夹支持真实打开、位置显示和只读内容预览。
- 预览必须有数量上限，不递归扫描整个目录。
- 大目录、无权限和离线目录必须快速降级，不阻塞桌面。

### FR-2.4 布局

- 2/4/6/8 栏必须严格对应用户选择。
- 100个以上桌面项目时仍可滚动、折叠、拖动和恢复布局。
- 100%/125%/150%/200% DPI 下无文字裁切、按钮重叠和不可点击区域。
- 支持保存场景，并恢复布局、门户、壁纸、桌宠、性能和每屏映射。

### FR-2.5 真实文件动作

- 整理执行前显示 ActionPlan、目标目录、冲突和预计影响。
- 默认只移动用户确认的普通文件，不自动移动程序、系统入口和未知快捷方式。
- 每个动作有日志、撤销和中断恢复记录。
- 恢复不得覆盖同名新文件。

## FR-3 壁纸与媒体

### FR-3.1 壁纸库

- 分类、搜索、预览、一键应用、收藏、保存原图和删除用户素材。
- 内置素材与用户素材分区显示。
- 每项记录来源、文件哈希、尺寸、类型、授权状态和降级封面。
- 用户素材库具备容量上限、重复检测、缩略图缓存和损坏恢复。

### FR-3.2 静态壁纸

- 应用后真实桌面宿主立即更新。
- 应用退出、Explorer 重启、睡眠唤醒和系统重启后按设置恢复。
- 支持填充、适应、拉伸、居中和每显示器独立策略。
- 保留原系统壁纸快照并支持恢复。

### FR-3.3 动态壁纸与Live Photo

- 支持 H.264 MP4 基线；其他编码通过能力检测决定是否允许导入。
- 支持播放、暂停、继续、循环、静音和静态封面降级。
- Live Photo 作为“静态封面+配对视频”导入，不依赖 Apple 专用运行时。
- 解码失败时保留上一帧或静态封面，禁止黑屏闪烁。
- 全屏游戏、锁屏、电池、节能和低性能档位自动暂停或降级。

### FR-3.4 壁纸创作

- 上传本地图片，增加签名、文字、贴纸和基础位置调整。
- 导出标准 16:9 PNG，并可保存进用户壁纸库。
- 不自动上传用户图片。
- 导出素材的授权责任和分发边界必须可见。

## FR-4 天气与桌面特效

- 支持自动定位、手动城市、OpenWeatherMap 和 Open-Meteo 降级。
- 雨、雪、雾、落叶、星光、雨光和光晕可叠加在静态壁纸之上。
- 多层效果具备独立开关、强度和质量档位。
- 核显和电池环境自动减少粒子数量、模糊半径和更新频率。
- 全屏、锁屏、休眠和壁纸暂停时停止非必要渲染。
- 网络失败使用缓存或手动天气，不影响应用启动。

## FR-5 桌宠

### FR-5.1 角色与动作

- 五个当前角色均可选择、缩放和跨显示器移动。
- 每个公开角色至少具备 idle、walk、happy、thinking、sleep 和 interaction 六类透明动作。
- 动作使用真实素材或合格骨骼动画，不使用遮挡人物的廉价 CSS 贴纸冒充换装。
- 没有真实服装帧时，设置中明确显示“暂无换装”。

### FR-5.2 人格与对话

- 人格、话频率、动作频率和角色身份从设置实时读取。
- AI 对话携带最近上下文，并控制最大历史长度和 Token。
- 不同人格有明显但不冒犯的语气、主动话题和问题处理方式。
- 点击、右键、定时气泡和 AI 回复均使用当前人格。
- 右键菜单包含对话、人格、换装、设置和关闭。

### FR-5.3 桌宠制作

- 本地图片抠图、阈值调整、透明 PNG 导出。
- 导入前显示尺寸、透明度和裁剪预览。
- 用户可为动作槽分别添加素材并预览组合。
- 资源进入正式角色库前进行完整性、容量和损坏校验。

### FR-5.4 视觉模型工作流

- 仅在用户显式选择图片并确认后调用视觉模型。
- 自动识别人像/动物/物体、外观特点和适合的人格候选。
- 输出结构化角色设定、禁用词、口吻、动作建议和提示词草案。
- 用户审核后才保存，不自动执行文件或桌面动作。
- 记录提供商、模型、费用估算和失败重试；失败不扣除本地素材。

## FR-6 AI与自动化

- 支持本地降级、DeepSeek、MiMo 和 OpenAI-compatible 配置。
- API Key 只经 Electron `safeStorage` 保存，不返回 renderer、不写日志。
- 连接测试不写聊天历史。
- Luna 生成标准结构化 ActionPlan，未知或高风险请求只给建议。
- 删除、覆盖、批量移动、运行命令和修改系统设置必须二次确认。
- AI 可切换已审核的本地壁纸，但不能访问未授权目录或上传桌面内容。
- 断网、余额不足、限流和服务不可用时显示可执行错误，不阻止本地功能。

## FR-7 设置、隐私与数据

- 深色、浅色和跟随系统主题在主窗口与设置窗口保持一致。
- 隐私中心展示联网项目、暂停状态、数据位置和保留范围。
- 支持导出脱敏诊断、本地数据和素材清单。
- 支持清理缓存、重建缩略图和覆盖初始化。
- 彻底删除应清除数据库、聊天、动作历史、诊断和授权记录，并恢复系统桌面。
- 诊断包不得包含 API Key、邮箱、真实用户名、私人文件名和完整路径。

## FR-8 安装、更新与发布

- 全新安装、覆盖安装、中文路径、标准用户、无网安装和卸载可用。
- 卸载提供“保留个人数据”和“彻底删除”两种明确选择。
- 安装、升级、卸载和失败回滚均恢复桌面图标、任务栏和原壁纸。
- V5公开Beta默认使用GitHub Releases手动更新。
- 自动更新仅在正式HTTPS源、签名、灰度和回滚全部完成后启用。
- 安装包、卸载器和更新包必须有有效 Authenticode 与时间戳才能面向公众分发。

## 6. 非功能需求

## NFR-1 性能

参考轻薄本、1080p、Intel核显：

| 场景 | V5目标 |
|---|---|
| 静态壁纸待机 | CPU中位数不高于1%，P95不高于3% |
| 1080p动态壁纸 | CPU中位数尽量低于5%，无持续掉帧 |
| 内存 | 24小时末值不超过稳定基线15%，无单调增长 |
| 全屏暂停 | 2秒内停止视频解码和高频粒子 |
| 退出 | 无Project D残留进程，系统桌面完整恢复 |

性能不达标时按顺序降级：粒子数量、模糊、帧率、视频分辨率、动态壁纸。

## NFR-2 安全

- 所有窗口保持 sandbox、contextIsolation、webSecurity 和禁用 Node integration。
- IPC 按窗口和路由授权，所有文件路径由主进程验证。
- 依赖漏洞、SBOM、秘密扫描和诊断脱敏进入发布门禁。
- 用户导入的视频、图片和压缩资源不作为可执行内容加载。
- 远程配置不得关闭桌面恢复等安全核心。

## NFR-3 可靠性

- 无已知P0：无法启动/退出、白屏、文件丢失、桌面无法恢复、安装损坏、秘密泄露。
- P1：崩溃、高占用、多屏错误、睡眠唤醒黑屏必须在公开Beta前关闭或明确隔离。
- 所有资源、窗口、Worker、定时器、IPC、子进程和数据库对象有所有者及清理路径。

## NFR-4 可访问性与体验

- 关键按钮具备可读名称、键盘焦点和足够对比度。
- 100%-200% DPI、窄窗口和长文本不裁切。
- 错误提示说明发生了什么、是否影响文件、如何恢复。
- 不在界面中宣称尚未完成或未验证的能力。

## 7. 发布门槛

## Gate A：客户端

- 自动化全绿，覆盖率不低于现有V4门槛。
- 当前源码打包、启动、退出、强杀、白屏和归位通过。
- 无已知P0，P1有责任人和截止日期。

## Gate B：真实硬件

- Windows 10/11。
- Intel、AMD、NVIDIA。
- 单屏、双屏、至少一次三屏。
- 1080p、2K、4K、横屏、竖屏、负坐标。
- 100%、125%、150%、200% DPI。
- 睡眠/唤醒20次、锁屏/解锁20次、显示器热插拔50次。

## Gate C：稳定性

- 4小时交互浸泡。
- 24小时空闲浸泡。
- 视频100次循环、壁纸300次切换。
- 无持续内存上涨、无不可恢复黑屏、无残留进程。

## Gate D：安装与供应链

- 干净机安装、覆盖升级、卸载和回滚通过。
- SHA256、SBOM、Commit SHA、构建摘要齐全。
- Authenticode 有效并带时间戳。
- Defender 与至少一种第三方安全产品无高风险阻断。

## Gate E：法律与素材

- MIT代码许可证的权利主体和第三方依赖兼容性确认。
- 明确 MIT 只覆盖代码，不覆盖壁纸、桌宠和用户素材。
- 所有随包素材从 `pending-evidence` 变为 `approved`，否则从公开包移除。
- 隐私政策、用户协议、免责声明经实际运营主体与法律审核。
- GitHub私密漏洞报告或长期安全邮箱可用。

## 8. V5完成定义

V5只有同时满足以下条件才可称为“公开免费Beta候选版”：

1. 当前 Stage 50 代码形成可追溯提交、版本、安装包和哈希。
2. 全部 P0 关闭；P1 不影响桌面安全、文件安全、安装与恢复。
3. 桌面整理、壁纸、天气、桌宠、AI、设置、托盘和恢复核心路径可用。
4. 真实硬件、安装、4小时和24小时测试有对应构建哈希证据。
5. 代码签名、素材授权、隐私政策和用户协议门禁关闭。
6. 发布说明明确已知限制，不宣传支付、云同步、Live2D或未完成能力。

## 9. 版本命名建议

- V5开发期：`0.3.0-dev`
- 功能冻结：`0.3.0-alpha.1`
- 硬件与安装验收：`0.3.0-beta.1`
- 公开免费Beta候选：`0.3.0-rc.1`
- 公开免费Beta：`0.3.0`

是否升级到 `1.0.0` 应由真实公开用户反馈、稳定性和支持能力决定，不以功能数量决定。
