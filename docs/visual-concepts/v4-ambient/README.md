## 提示词摘要

所有生成均把用户提供的两张截图作为风格与构图参考，而不是编辑目标。

### 01 雨夜安静态

16:9 的 Windows 沉浸式桌面。雨夜海岸、暖色城镇灯光、近景水滴和远景薄雾。壁纸至少 92% 可见，仅保留四项边缘工具、微型状态和一个克制气泡。

### 02 明亮自适应

清晨湖畔花园和自然光。亮色壁纸上使用烟灰中性高透玻璃。保留少量原生桌面图标、边缘工具和天气时间，不使用白色大面板。

### 03 真实雨幕

展示近景滑落水滴、中景不同速度雨丝、远景雨幕、海岸薄雾和湿地反射。只保留极少天气控制，禁止均匀线条和全屏模糊。

### 04 飘雪与雾

冬季湖边车站、暖灯、冷雪。雪花具有近中远尺寸与清晰度差异，地面和屋檐有轻微积雪暗示。角色与场景光照一致。

### 05 桌宠助手

月夜观星花园。角色位于壁纸负空间停留带，动作、表情、气泡和临时助手面表现同一事件。完整湖面仍是画面中心。

### 06 空间式整理

文件和文件夹保持原生图标感。分组只用标题胶囊、角标和局部淡玻璃表达。底部集中预览、确认、撤销和关闭，禁止大型卡片矩阵。

### 07 壁纸创作器

壁纸作为全屏编辑画布。底部胶片带、左侧工具轨和小型检查器处理裁剪、动态、天气和应用。画布上允许签名与贴纸编辑。

### 08 混合显示器

一台横屏和一台竖屏显示器。壁纸独立裁剪，控件位置根据安全区迁移，桌宠尺寸和锚点独立计算，避免跨屏拉伸。
