# Project D 未来商业化 GA 门禁附录

- 状态：未来参考，不阻断 V6.0 个人开源候选版
- 日期：2026-07-27

## 1. 边界

V6.0 可以在没有支付、会员、云同步、商业灾备和正式签名的情况下完成个人开源候选版，但不得因此宣称达到商业 GA。

本附录是未来范围索引，不是第二套当前发布清单。现有 `docs/V4_EXTERNAL_GATES.md` 继续作为外部输入和证据状态台账；决定进入商业化开发时，应以本附录为范围、以该台账的真实证据为输入，建立经权利人和专业人员确认的 V6 商业 GA 检查表。任何勾选、负责人和证据路径都应记录在届时的正式检查表中。

## 2. 签名、安装与更新

- 安装包、主程序、卸载器和更新包使用可信 Authenticode 签名；
- 验证时间戳、证书轮换、Defender 与 SmartScreen；
- 覆盖中文路径、标准用户、无网、覆盖安装和卸载；
- 卸载恢复壁纸、图标和任务栏，残留进程为 0；
- 建立稳定与灰度通道，支持 5%、20%、50%、100%；
- 更新元数据签名，更新包校验签名与 SHA-256；
- 断网、空间不足、进程占用和中断可恢复；
- 验证 N-2 到 N 的迁移与回滚；
- 支持暂停问题版本、撤回和用户通知。

## 3. 账号、设备与权益

- 密码服务端强哈希；
- Token 有有效期、刷新、吊销和设备绑定；
- 设备数量和换机恢复规则清楚；
- 退款和封禁撤销权益；
- 客户端本地状态不单独决定会员；
- 离线宽限期和时钟回拨有策略；
- 账号、设备、权益变更写审计日志。

## 4. 支付、订单与退款

- 使用持牌支付服务商，不在客户端保存支付密钥；
- 价格、订单状态和权益由服务端决定；
- 回调验签、幂等和防重放；
- 重复支付不重复开通；
- 支付成功但未到账可对账修复；
- 订单可查询追踪；
- 退款后撤销对应权益；
- 处理超时、断网、关闭页面和重复回调；
- 建立财务对账和申诉流程；
- 个人收款方式在正式接入前完成平台规则与主体资格审核。

## 5. 隐私与法律

- 隐私政策和用户协议由合格专业人士审核；
- 列明设备信息、日志、崩溃、文件元数据和联网行为；
- 提供同意、撤回、导出和删除；
- 明确未成年人、适用地区和争议处理；
- 用户内容有侵权投诉和下架机制；
- AI 内容有安全审核与申诉；
- 建立数据保留、备份和删除周期；
- 第三方处理者和跨境传输单独说明。

## 6. 素材与内容

- 壁纸、视频、角色、动作、字体、音频和贴纸有独立授权；
- 记录作者、来源、用途、地域、期限和再分发权；
- AI 素材记录模型、条款和生成日期；
- 不默认认为 AI 生成即可商用；
- 用户上传内容有敏感、侵权和恶意文件审核；
- 用户内容不自动公开；
- 公开素材支持下架与替换。

## 7. 安全

- API Key、支付密钥和管理员接口不进入客户端；
- 服务端权限最小化；
- 更新、下载和用户上传有完整性保护；
- 对本地权益篡改进行威胁建模；
- 建立私密漏洞报告渠道和响应时限；
- 依赖漏洞、SBOM 和供应链审计纳入发布；
- 定期进行第三方安全评估。

## 8. 运维与灾备

- 生产遥测经用户同意并最小化；
- 监控登录、支付、更新、崩溃和恢复率；
- 建立服务状态页、客服工单和问题分级；
- 维护 RTO、RPO、备份恢复和演练；
- 远程配置签名、限权和防回滚；
- 建立 P0/P1 值班与用户通知。

## 9. 商业 GA 完成定义

只有以下全部关闭，才可以宣称商业 GA：

- 真实硬件和 24 小时稳定性矩阵通过；
- 安装、更新、回滚、卸载闭环通过；
- 发行二进制完成可信签名；
- 支付、订单、权益、退款和对账通过生产验收；
- 隐私、协议和素材授权完成专业审核；
- 安全、监控、灾备、客服和漏洞响应可运行；
- 无已知 P0，P1 有明确处置；
- 发布、撤回和用户数据恢复有演练证据。
