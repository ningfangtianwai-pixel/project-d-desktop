# Project D 架构与安全边界

![Project D 系统架构](./architecture.svg)

## 分层原则

| 层 | 职责 |
| --- | --- |
| Vue Renderer | 展示工作空间、搜索、场景、设置和行动预览，不直接调用 Node 或 Windows API |
| Electron Preload | 通过类型化、白名单 IPC 暴露最小能力，形成渲染层与主进程之间的信任边界 |
| Electron Main | 管理窗口、系统托盘、生命周期、权限、隐私和更新策略 |
| Domain services | 搜索、门户、场景、行动引擎、恢复、壁纸、天气和桌宠 |
| Local data | 保存设置、场景、操作日志和恢复证据，默认不依赖云端账户 |
| Optional providers | AI 与天气属于可暂停的外部能力，不得阻塞桌面核心和恢复路径 |

## 动作安全链路

```text
用户意图 → 本地上下文 → 行动计划 → 用户确认 → 执行日志 → 完成或回滚
```

- 搜索结果使用不透明、可过期句柄跨越进程边界。
- 文件夹门户只允许用户明确授权的目录，并防止路径逃逸。
- 桌面整理先生成预览，处理目标冲突后再执行。
- `Esc`、安全归位、恢复中心和启动恢复共同保护真实 Windows 桌面状态。
- 外部网络或 Provider 不可用时，本地搜索、场景与恢复能力继续工作。
