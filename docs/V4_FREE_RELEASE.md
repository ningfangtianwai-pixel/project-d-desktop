# Project D V4 免费发布范围

## 1. 发布定位

V4 的目标是提供一个无需 Project D 账号、支付、会员或云端服务即可使用的 Windows 免费版。核心桌面能力应在离线状态下启动、运行、恢复和退出；联网功能必须是可选增强，而不是启动条件。

“免费发布”描述价格与产品范围，不自动赋予源码开源许可，也不替代素材授权、隐私合规、代码签名或质量验收。

## 2. 包含能力

- 桌面扫描、整理计划预览、用户确认、执行、撤销和恢复。
- 原桌面上的容器、门户、搜索、场景、快捷键和自动规则。
- 静态/动态壁纸、天气效果、多显示器布局策略和性能降级。
- 桌宠选择、行为、人格、气泡和本地设置。
- 本地数据导出、彻底删除、隐私暂停和诊断信息生成。
- 用户自行配置的天气与兼容 AI 提供商。

这些能力必须保持托盘安全归位、异常退出恢复和原桌面状态恢复路径。

## 3. 离线与联网边界

默认本地：

- 桌面文件索引、场景、规则、动作计划和动作历史。
- 设置、桌宠状态、聊天历史和诊断日志。
- 本地壁纸、桌宠素材与 Everything/Windows Search 适配。

可选联网：

- 天气：根据用户启用的定位方式请求天气服务；无 Key 时可使用已声明的降级服务。
- AI：仅在用户选择提供商并配置 Key 后发送用户输入及必要上下文。
- 更新：仅在可信更新端点、签名和回滚门禁完成后启用公开自动更新。

所有联网能力都应可暂停；失败不能阻止应用启动、桌面恢复或本地整理。

## 4. 明确不包含

- 生产账号注册、登录和跨设备身份。
- 微信、支付宝、银行卡支付、订单、退款和会员权益服务。
- 云同步、云备份、云端遥测或远程桌面内容采集。
- 由 Project D 托管的用户 API Key 代理服务。
- 未经过授权审核的素材商店或用户内容分发平台。

仓库中的账号、订单、支付或权益领域骨架仅用于未来设计和测试，不是 V4 免费版可用服务，也不得出现在 UI 中形成误导。

## 5. 数据与隐私承诺

- 不把真实 API Key 写入源码、构建产物、日志或诊断包。
- 不默认上传桌面文件名、目录结构、聊天历史、截图或设备内容。
- 文件动作先预览、再确认，并保留恢复证据。
- 用户可以暂停外部请求、导出本地数据并请求彻底删除。
- 日志仅记录故障定位所必需的信息；展示或导出时对个人绝对路径和私人文件名脱敏。

正式发布时，应用行为、隐私政策、用户协议和帮助文档必须一致。

## 6. 发布质量底线

P0 阻断项包括：应用无法启动/关闭、白屏遮挡桌面、桌面图标无法恢复、文件丢失、安装/升级损坏、秘密泄露。

公开测试前至少需要：

- 类型检查、单元测试、覆盖率、构建和打包通过。
- 安装、卸载、覆盖升级、异常退出和恢复测试通过。
- Windows 10/11 与单屏/多屏/DPI 矩阵有真实证据。
- 安装包经过恶意软件扫描并使用可信代码签名。
- 素材台账中的每个分发资源都有来源、作者、授权范围和证据。
- 隐私政策与用户协议完成法律审核。

## 7. 许可证状态

许可证必须由仓库权利人明确选择。选择前：

- 不创建虚假的 MIT、Apache-2.0、GPL 或其他 `LICENSE`。
- 不声称项目已经开源。
- 公开可见源码默认不授予复制、修改、再分发或商用许可。
- 不合并权利归属不明的外部贡献。

候选许可证评估需要同时考虑产品源码、第三方依赖、生成素材、用户提供素材和未来商业服务边界。最终决定与证据记录在 `LICENSE`、第三方声明和素材台账中。

## 8. 发布判定

本地构建与自动化测试通过后，可以称为“可测试构建”。只有 [V4_EXTERNAL_GATES.md](V4_EXTERNAL_GATES.md) 中的发布阻断项全部关闭，才可以称为“可公开分发版本”。
